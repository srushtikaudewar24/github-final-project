# Paradise Nursery — Online Plant Shop

Paradise Nursery is a responsive React and Redux Toolkit shopping-cart application for browsing and buying houseplants.

## Features

- Welcoming landing page with background photo, company information, and Get Started button.
- Eighteen different houseplants displayed in three categories (six per category): Indoor Classics, Air Purifiers, and Succulents & Cacti.
- Plant cards with a thumbnail, name, description, price, and Add to Cart button.
- Shared navbar with Home, Plants, and Cart, plus a dynamic total-item badge.
- Redux shopping cart with addItem, removeItem, and updateQuantity reducers.
- Cart page with item thumbnails, quantities, line totals, grand total, delete, and Coming Soon checkout.

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite. The application uses Vite, React, react-redux, and @reduxjs/toolkit.
