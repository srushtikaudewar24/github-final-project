# Simple Interest Calculator

This is Srushti Kaudewar's **github-final-project** for the Coursera Introduction to Git and GitHub assignment.

This project includes a Bash script, `simple-interest.sh`, that calculates simple interest from the principal amount, annual interest rate (percent), and time period (years).

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Run the calculator

```bash
bash simple-interest.sh
```

Enter the principal, annual interest rate, and time period when prompted.
